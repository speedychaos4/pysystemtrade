Architecture Type: Stage Pipeline Pattern

├─ 8 Processing Stages (RawData → Rules → ForecastScaleCap → ForecastCombine
│                      → PositionSizing → Portfolio → Account → Results)

└─ Performance Metrics

Key Design Principles:
  1. Configuration-driven (zero code changes for parameter tweaks)
  2. Multi-layer data abstraction (swap storage backends)
  3. Intelligent caching (10-100x faster on large backtests)
  4. Stage-based modularity (independent, testable components)
  5. Production-ready (Interactive Brokers integration)

Repository Size:
  - 592 Python files
  - 50,000+ lines of code
  - 16 main modules
  - 8+ pre-built trading rules
  - 15+ quantitative tools

Reusability for Options:
  - 60-70% directly reusable

  - Architecture is asset-class agnostic
